F2F AI Chatbot

OpenAI bağlı floating widget — site ziyaretçilerine anında yanıt. Sağ alttaki balona tıklayarak deneyin.

Kuruluma bak

WordPress kurulumu

  1. f2f-ai-chatbot klasörünü wp-content/plugins/ altına kopyalayın (veya zip yükleyin).
  2. Eklentileri etkinleştirin → Ayarlar → F2F AI Chatbot.
  3. OpenAI API anahtarınızı girin, sistem promptunu ve marka rengini ayarlayın.
  4. Widget otomatik olarak tüm sayfalarda sağ altta görünür.

API anahtarı yalnızca sunucuda saklanır; tarayıcıya gönderilmez. Bu demo sayfası aynı widget arayüzünü Node üzerinden gösterir.
